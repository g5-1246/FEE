A. React – JavaScript Library
1. React is an open-source JavaScript library developed by Meta.
2. It is used to build interactive and dynamic user interfaces.
3. It follows a component-based architecture.
4. Components are reusable parts of a webpage.
5. It uses JSX to write HTML-like code in JavaScript.


B. State – Changing Data in React
1. State stores data that can change over time.
2. It is managed using the useState hook.
3. It helps create dynamic and interactive user interfaces.
Examples include counters, usernames and form inputs.


C. Zustand – Global State Management
1. Zustand is a lightweight state management library for React.
2. It uses a centralized store to maintain global state.
3. It avoids prop drilling.
